Notes

This combines Postgres full-text keyword search with pgvector semantic search.

Each search returns its top candidates, then reciprocal rank fusion (RRF) merges them into a single ranked list.

Items that score well in both lists rise to the top. An item that appears in only one list can still appear in final list if ranked highly in source list.

All of this runs inside Postgres, no separate search service required.

Embeddings are generated locally with a sentence-transformers model (snowflake-arctic-embed-s, 384 dims) over each topic's title + body. They're computed when sample content is loaded, and re-runs of the loader skip topics whose content hasn't changed.
